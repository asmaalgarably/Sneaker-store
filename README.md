# STEP — Sneaker Store Landing Page

A responsive sneaker store landing page built with pure **HTML** and **CSS**, created as part of the **"أطلق متجرك" (Launch Your Store)** workshop organized by **Qafza**.



## 🎯 About the Project

STEP is a modern, minimal e-commerce landing page concept for a sneaker brand. The project focuses on building a clean, fully responsive front-end from scratch — no frameworks, just semantic HTML and hand-written CSS.

## ✨ Features

- 🖥️ Fully responsive layout (Desktop, Tablet, Mobile)
- 👟 Hero section with call-to-action
- 🛍️ Featured products grid with pricing
- ⭐ Customer testimonials section
- 📣 Call-to-action banner
- 🧭 Simple, clean navigation and footer

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox / Grid)

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/asmaalgarably/<repo-name>.git

# Navigate into the project folder
cd <repo-name>

# Open index.html in your browser
```

No build tools or dependencies required — just open `index.html` directly in your browser.

## 📱 Responsive Design

The layout adapts across breakpoints to ensure a smooth experience on desktop, tablet, and mobile devices. Design references are available under the `designs/` folder.
